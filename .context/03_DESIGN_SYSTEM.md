# Visual Design System & Token Contract

## Typography Matrix
- **Display Headings**: `Cormorant Garamond`, Georgia, serif (Weights: 300, 400, 600) — High-end editorial and architectural gravity.
- **Body / Interface / Accents**: `Jost` / `Montserrat`, sans-serif (Weights: 300, 400, 500, 600, 700) — Modern, legible, geometric precision.

## Core Brand Palette (Immutable Constants)
- `--c-terracotta`: `#C0673F` (Primary Accent & CTA)
- `--c-terracotta-dark`: `#A8552F` (Hover States)
- `--c-sand`: `#DCC7B1` (Warm Metallic Accent / Subtle Borders)
- `--c-cream`: `#F7F3ED` (Warm Luxury Off-White)
- `--c-charcoal`: `#1F2A2E` (Deep Architectural Ground)
- `--c-grey`: `#8A8F93` (Secondary / Supporting Text)
- `--c-green`: `#25D366` (WhatsApp Floating Action)

## Visual Archetypes
1. **Option A (Cinematic Dramatic)**: Full-bleed looping Red Sea aerial video backdrop, centered monumental typography, ambient light glows, luxury feel.
2. **Option B (Editorial Split)**: 55/45 asymmetric architectural split hero, side-by-side video narrative with quick-access destination links and bold key statistics.
